  # webmcpx

  ### Make your site agent-ready.

  Standard WebMCP tools for any website, and a linter for your own.

  [**Scan your site &rarr;**](https://webmcpx.dev) &middot; [**Get started &rarr;**](https://webmcpx.dev/#fix) &middot; [npm](https://www.npmjs.com/package/webmcpx)

  </div>

  ---

  AI agents are already reading your pages. Give them typed tools to find the right passage, read page content and understand where they are.

  **webmcpx brings those tools to your website with one script tag.** They run in the user's tab, alongside the page and the session they already have.

  ### One line to get started

  Add this before `</body>`:

  ```html
  <script type="module" src="https://cdn.jsdelivr.net/npm/webmcpx/src/auto.js"></script>
  ```

  Prefer npm? `npm i webmcpx`

  WebMCP support is required. Where the browser API is missing, the script does nothing. Start with the [site scanner and installation guide](https://webmcpx.dev).

  ### What agents can do

  | Tool | Purpose |
  | --- | --- |
  | `search_page` | Find relevant passages on the current page. |
  | `fetch_as_markdown` | Read page content as Markdown, with paged results. |
  | `get_page_context` | Understand the current page's context. |

  Building your own tools? The webmcpx linter helps check tool names, descriptions and tool budgets. Explore the [official site](https://webmcpx.dev) for details and benchmark methodology.
