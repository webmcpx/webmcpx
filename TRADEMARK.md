# webmcpx trademark policy

The webmcpx code is licensed under MIT OR Apache-2.0. Those licenses cover the code only: they grant no
rights to the name **webmcpx** or to its logos (the Junction, the Card and the Page with slot, in
`site/static/brand-assets/`). This policy says how you can use them. It is short on purpose, and modeled on
the Rust and Python trademark policies.

The goal is simple: anyone should be able to talk about, build on and share webmcpx, and nobody should be
misled about what is official.

## You can, without asking

- Refer to webmcpx truthfully: "built with webmcpx", "compatible with webmcpx", "a webmcpx plugin".
- Name a plugin or extension `webmcpx-plugin-<name>` or `@your-scope/webmcpx-<name>`, as long as its README
  says it is not part of the official project.
- Write articles, tutorials and books, give talks, and run free meetups or workshops about webmcpx.
- Use the unmodified logo to link to the project, in its documented colors and with its clear space.
- Fork the code. If you redistribute a version with material changes, give it another name; you may say
  "based on webmcpx".

## Ask first

Write to the maintainers (open an issue titled "Trademark request") before:

- using "webmcpx" or a logo in the name of a commercial product or service;
- selling merchandise with the name or logo;
- running a paid event named after webmcpx;
- using a modified logo.

## Never

- Suggest that the webmcpx maintainers endorse, certify or sponsor you, or that your project is official.
- Use names, logos or package names confusingly similar to webmcpx (for example `webmcp-x`, `web-mcpx`, or
  look-alike marks), including typosquatting on package registries.
- Use the name or logos in a way that is misleading or harmful to the project.
